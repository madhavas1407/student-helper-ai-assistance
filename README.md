# 🎓 Student Helper AI Assistance

An intelligent, full-stack AI-powered study copilot designed for students, developers, and researchers. Built with modern UI/UX design, real-time code execution, and Gemini AI integration.

## 🚀 Live Demo
🌐 **Website:** https://madhavas1407.github.io/student-helper-ai-assistance/

## ✨ Key Features
- **Smart AI Tutor:** Instant academic explanations, notes summarization, and viva preparations powered by Google Gemini.
- **▶ Universal Code Runner:** Run code snippets directly from the browser using a local Python/Flask backend execution engine.
- **Voice Typing & Audio TTS:** Ask questions using your voice and listen to AI answers hands-free.
- **PDF Export:** Export your study sessions and code solutions into clean PDF documents.
- **System Health Diagnostics:** Built-in tools for PC health checks, storage cleanup, and system log troubleshooting.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Modern JavaScript, Marked.js, html2pdf.js
- **Backend:** Python, Flask, Flask-CORS, Subprocess
- **AI Model:** Google Gemini API
